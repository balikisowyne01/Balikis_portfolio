# Nurudeen Balikis — Data Analyst & Business Intelligence Specialist Portfolio

A modern, high-performance, responsive portfolio built with **Vite + React**, **Bootstrap 5**, and **Lucide React**, inspired by clean high-contrast executive design systems.

---

## 🚀 Key Features

- **Executive Analytics Design System**:
  - Crisp typography using *Plus Jakarta Sans* and *JetBrains Mono*.
  - Analytics-focused color palette: Deep Slate Navy (`#0f172a`), Electric Cyan (`#0284c7`), Emerald Data Teal (`#10b981`), and Royal Indigo (`#4f46e5`).
  - Frosted glass sticky navigation bar and smooth interactive hover elevations.

- **Dynamic Interactive Data Visualizer**:
  - Live analytics simulator on the homepage demonstrating Sales & Margin Variance, Cohort Retention Decay, and A/B Test Funnel distributions.

- **Comprehensive Case Studies with Quantified Business ROI**:
  - Power BI & DAX customer intelligence dashboard (OmniRetail).
  - Python & Machine Learning churn prediction pipeline (FinPulse).
  - PostgreSQL emergency wait-time optimization study (MediCare).
  - Advanced Excel Power Query & VBA logistics cost model (GlobalLogistics).
  - E-commerce A/B testing statistical significance analysis (NovaStore).
  - Global workforce retention & HR metrics dashboard (TalentMetrics).

- **Technical Stack & Architecture**:
  - Categorized proficiency bars across BI, SQL, Python, and Methodologies.
  - Interactive technology matrix filter.
  - 6-Stage Analytical Lifecycle roadmap.

- **Client Services & Inquiries**:
  - 6 core data service offerings with deliverables and ideal client fits.
  - Interactive contact and hiring form with SweetAlert2 notifications.

## 📷 Profile Picture Setup

When Nurudeen Balikis supplies her profile photo:
1. Save the photo to: `src/assets/profile.jpg` (or `.png`).
2. In [src/components/AvatarPlaceholder.jsx](file:///e:/balikis_portfolio/src/components/AvatarPlaceholder.jsx), import the image and pass it as `customSrc`.
3. If no image is provided, the bespoke analytical female silhouette SVG avatar displays automatically with an animated pulse ring.
